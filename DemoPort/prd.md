# PRD: 개발자 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 개인의 기술 역량, 프로젝트, 경력을 소개하는 프로필(포트폴리오) 웹사이트 |
| 연락처 | ar2yoo@infiniq.co.kr |
| 주력 분야 | Python, HTML5, iOS 앱 개발 |

## 2. 목표

- 방문자(채용 담당자, 클라이언트, 협업 개발자)가 개발자의 핵심 역량을 **30초 안에** 파악할 수 있도록 한다.
- 주력 기술(Python / HTML5 / iOS)별 대표 프로젝트를 보여준다.
- 이메일을 통해 쉽게 연락할 수 있는 경로를 제공한다.

## 3. 대상 사용자

1. **채용 담당자 / 인사팀** – 기술 스택과 경력을 빠르게 확인하고 싶음
2. **잠재 클라이언트** – 외주·협업 가능 여부와 결과물 품질을 확인하고 싶음
3. **동료 개발자** – 프로젝트 코드와 기술적 접근 방식을 보고 싶음

## 4. 주요 기능 (페이지 구성)

### 4.1 Hero (메인 소개)
- 이름, 한 줄 소개 (예: "Python · HTML5 · iOS 개발자")
- 프로필 이미지
- CTA 버튼: "프로젝트 보기", "연락하기"

### 4.2 About (자기소개)
- 간단한 자기소개 및 개발 철학
- 경력 요약

### 4.3 Skills (기술 스택)
주력 분야를 세 카테고리로 구분하여 표시한다.

| 카테고리 | 주요 기술 (예시) |
|----------|------------------|
| **Python** | Python 3, FastAPI / Django / Flask, 데이터 처리(Pandas), 자동화 스크립트 |
| **HTML5 / Web** | HTML5, CSS3, JavaScript, 반응형 웹, Canvas / Web API |
| **iOS** | Swift, SwiftUI, UIKit, Xcode, App Store 배포 |

- 기타 도구: Git, GitHub 등

### 4.4 Projects (프로젝트)
- 프로젝트 카드 목록 (썸네일, 제목, 요약, 사용 기술 태그)
- 기술 분야별 필터 (전체 / Python / HTML5 / iOS)
- 상세 링크: GitHub 저장소, 데모 URL, App Store 링크

### 4.5 Experience (경력)
- 타임라인 형태로 회사·직무·기간·주요 성과 표시

### 4.6 Contact (연락처)
- 이메일: **ar2yoo@infiniq.co.kr** (`mailto:` 링크)
- GitHub 등 외부 링크 (추후 추가)

## 5. 비기능 요구사항

- **반응형 디자인**: 모바일 / 태블릿 / 데스크톱 모두 지원
- **성능**: 초기 로딩 2초 이내, Lighthouse 성능 점수 90 이상
- **접근성**: 시맨틱 HTML5 태그 사용, 이미지 alt 텍스트, 키보드 탐색 지원
- **SEO**: 메타 태그, Open Graph 태그 설정
- **다크 모드**: 시스템 설정에 따른 라이트/다크 테마 지원
- **유지보수성**: 프로젝트·경력 데이터는 별도 데이터 파일(JSON 등)로 분리하여 쉽게 수정 가능

## 6. 기술 스택 (구현)

- **프론트엔드**: HTML5, CSS3, Vanilla JavaScript
- **호스팅**: GitHub Pages 또는 정적 호스팅 서비스
- **버전 관리**: Git
